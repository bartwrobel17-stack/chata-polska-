# Chata Polska Rawicz

Nowy, czysty projekt Next.js przygotowany do wdrożenia na Vercel.

Adres sklepu: Spokojna, 63-900 Rawicz.

## Zmienne Vercel

- BLOB_READ_WRITE_TOKEN – token Vercel Blob
- ADMIN_PASSWORD – hasło do /admin

Po ustawieniu zmiennych właściciel może wejść na /admin i dodać wiele zdjęć naraz.
